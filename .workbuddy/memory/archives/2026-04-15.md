### 新增 API 路由（共22个端点）
**认证模块：**
- POST /api/auth/register
- POST /api/auth/login（记录登录历史）
- POST /api/auth/logout
- POST /api/auth/refresh
- GET /api/auth/me

**用户模块：**
- GET /api/users/check-username
- GET|PUT /api/users/[username]
- GET /api/users/[username]/repos

**仓库模块：**
- POST /api/repos（创建仓库）
- GET|PUT|DELETE /api/repos/[username]/[repoName]
- GET /api/repos/[username]/[repoName]/tree
- PUT /api/repos/[username]/[repoName]/star（切换star）
- PUT /api/repos/[username]/[repoName]/watch（切换watch）

**讨论区模块：**
- GET|POST /api/discussions
- GET|DELETE /api/discussions/[id]
- GET|POST /api/discussions/[id]/comments
- POST /api/discussions/[id]/accept/[commentId]

**搜索模块：**
- GET /api/search（repos/users/discussions）
- GET /api/search/suggest

**管理面板模块（全部需要admin权限）：**
- GET /api/admin/dashboard（含近7天趋势数据）
- GET /api/admin/users + GET /api/admin/users/[id]
- PUT /api/admin/users/[id]/ban（记录审计日志）
- GET /api/admin/repos + DELETE /api/admin/repos/[id]（记录审计日志）
- GET /api/admin/discussions + DELETE /api/admin/discussions/[id]（记录审计日志）
- DELETE /api/admin/discussions/comments/[commentId]（记录审计日志）
- GET /api/admin/reports + POST /api/admin/reports/[id]/handle（记录审计日志）
- GET /api/admin/audit-logs（支持按adminId/actionType/日期范围筛选）
- GET /api/health
