## 23:16 - 右键菜单语法错误修复

### 问题
全局右键菜单代码导致 Next.js 编译错误："Unexpected token `div`"

### 修复
使用 overlay 包装右键菜单，改用三元表达式替代条件块：
```jsx
{contextMenu && (
  <div className="overlay">
    <div className="context-menu">
      {contextMenu.type === 'user' && (...)}
      {contextMenu.type === 'repo' && (...)}
      {contextMenu.type === 'discussion' && (...)}
    </div>
  </div>
)}
```

## 23:09 - 修复封禁管理显示孤立封禁用户

### 问题
用户被封禁后，在"封禁管理"页面不显示。

### 原因
`UserBan` 表中可能没有记录（用户可能是通过其他方式设置的 `isBanned: true`）

### 修复内容
1. **API 修复** (`/api/admin/bans/route.ts`)：
   - 查询 `UserBan` 表时，同时查询 `User` 表中 `isBanned=true` 的孤立用户
   - 添加 `isOrphaned` 标记区分孤立封禁

2. **前端修复** (`admin/page.tsx`)：
   - 孤立封禁用户显示"孤立"徽章
   - 添加"创建记录"按钮（为孤立封禁创建 UserBan 记录）
   - 添加"解封"按钮（直接解除封禁）
