## 举报邮件通知功能 ✅

### 1. email-service.ts 新增函数
- `sendReportNotificationEmail()` - 发送举报通知邮件
- 支持三种通知类型：
  - **内容删除** (content_deleted) - 通知被举报人其内容已被处理
  - **举报驳回** (content_dismissed) - 通知举报人其举报未被采纳
  - **用户处罚** (user_penalized) - 通知被处罚用户

### 2. 举报处理 API 集成
- 文件：`src/app/api/v1/admin/reports/[id]/handle/route.ts`
- 处理举报后自动发送邮件给相关用户
- 邮件发送为异步，不影响主流程
