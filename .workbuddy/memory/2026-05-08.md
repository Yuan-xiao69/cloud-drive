### rate-limit.ts / cache.ts 安全修复

**修复的问题**：

1. **rate-limit.ts**：
   - X-Forwarded-For 伪造漏洞 → 添加 TRUSTED_PROXIES 配置 + IP 验证
   - 内存存储无上限 → LRU 淘汰策略（默认 10000 条）
   - cleanup() 同步阻塞 → 定时清理（60秒间隔）
   - RedisRateLimiter 死代码 → 集成到 checkRateLimit

2. **cache.ts**：
   - JSON.stringify 抛异常 → try-catch 包裹
   - KEYS 命令阻塞 Redis → 改用 SCAN 命令
   - 逐个删除 key → pipeline 批量删除

**新增环境变量**：
- `TRUSTED_PROXIES` - 可信代理 IP 列表
- `RATE_LIMIT_MAX_ENTRIES` - 内存存储最大条目数（默认 10000）
