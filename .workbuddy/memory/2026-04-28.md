### 8. 创建仓库页面"未登录"Bug 修复
- **根因**：`new/page.tsx` 用 `localStorage.getItem('accessToken')` 取 token，但项目 token 存在 Cookie 中，取到 null
- **修复**：改用 `tokenManager.getAccessToken()` 从 Cookie 读取，与项目其他 API 调用方式一致

### 9. 发布讨论后不跳转 Bug 修复
- **根因**：`discussions/new/page.tsx` 判断 `data.code === 200`，但 API 用 `created()` 返回 `code: 201`，条件不满足
- **修复**：`data.code === 200` → `data.code === 201`，发布后正确跳转到讨论详情页

### 10. 讨论详情页评论+点赞功能失效修复
- **评论 Bug**：CommentSection.tsx 请求未带 Authorization token + code 判断 `0` 不匹配 `created()` 返回的 201
  - 修复：所有 fetch 请求添加 `tokenManager.getAccessToken()` + code `0` → `201`
  - 涉及：handleSubmit、handleReply、handleAccept 三个函数
- **点赞 Bug**：LikeButton.tsx 的 `res.code === 0` 不匹配 `success()` 返回的 200
  - 修复：所有 code 判断 `0` → `200`（兼容保留 `0`）
  - 涉及：checkOwnership、checkStatus、handleLike 三个位置

### 11. 举报弹窗不弹出（内联显示）Bug 修复
- **根因**：`ReportModal` 使用 `modal-overlay` / `modal-content` 类名，但 `globals.css` 中没有定义这两个样式
- **修复**：在 `globals.css` 中添加通用 `.modal-overlay`（fixed + 遮罩）和 `.modal-content`（居中卡片）样式
- **影响范围**：所有使用这两个类名的弹窗组件均受益

### 12. 举报提交"无效的举报原因"Bug 修复
- **根因**：`ReportModal.tsx` 将 reason 英文 value（如 `spam`）转为中文 label（如 `垃圾信息`）发送，后端只接受英文值
- **修复**：直接发送英文 `reason`，移除 `.label` 转换

### 13. 举报用户"举报目标不存在"Bug 修复
- **根因**：前端传 `user.uid`（如 `000000001`），后端 `checkTargetExists` 只用 `where: { id }` 查 Prisma 主键，uid 和 id 不匹配
- **修复**：后端改为 `findFirst` + `OR: [{ id }, { uid }]`，兼容两种查找方式

### 14. 管理面板无限闪动刷新 Bug 修复
- **根因**：`admin/page.tsx` 三个 useEffect 依赖 `[admin]`，而 `admin` 是 `useAdminPage()` 返回的对象，每次渲染引用都不同 → 无限循环
- **修复**：将 `[admin]` 改为具体的 setter 函数引用（如 `[admin.setUserRole, admin.setLoadingRole]`），setter 引用稳定不会触发重渲染
- 涉及：关闭右键菜单 useEffect、加载角色 useEffect、Tab 切换加载数据 useEffect

### 15. 管理面板数据不显示 Bug 修复
- **根因**：`useAdminPage.ts` 全部 16 个 fetch 函数判断 `res.code === 0`，后端返回 `code: 200`，条件永远不满足
- **修复**：16 处 `res.code === 0` → `res.code === 200`
- 涉及：dashboard/users/repos/reports/reportDetail/reportStats/auditLogs/announcements/appeals/penalties/securityEvents/ipBlacklist/discussions/bans/activityLogs/backupFiles
