## 已处理问题

### 🔴 严重问题

#### 1. where.OR 条件覆盖问题
- **文件**: `admin/bans/route.ts` (GET 方法)
- **问题**: 直接给 `where` 顶层赋 OR，导致其他过滤条件被覆盖
- **修复**: 使用 AND 数组将状态过滤条件与用户过滤条件组合
- **状态**: ✅ 已修复

#### 2. 事务原子性问题
- **文件**: `admin/bans/route.ts` (DELETE 方法)
- **问题**: "解封用户 + 删除记录" 操作未包裹在事务中
- **修复**: 使用 `prisma.$transaction` 包裹
- **状态**: ✅ 已修复

### 🟡 中等问题

#### 3. switch case 块级作用域问题
- **文件**: `admin/appeals/route.ts` (POST 方法)
- **问题**: switch case 中直接声明 const 变量，未使用花括号包裹
- **修复**: 为 case 分支添加花括号
- **状态**: ✅ 已修复

#### 4. 审计日志调用问题
- **文件**: `admin/penalties/route.ts` (POST 方法)
- **问题**: 直接使用 Prisma 而非 recordAuditLog 工具函数
- **修复**: 替换为 recordAuditLog 函数
- **状态**: ✅ 已修复

#### 5. PR/Issue 评论 API 端点
- **文件**: `pulls/[id]/page.tsx`, `issues/[id]/page.tsx`
- **问题**: 页面调用 `/api/v1/repos/${username}/${repoName}/pulls/${prId}/comments` 端点
- **状态**: ✅ 已确认实现

#### 6. admin/hidden/route.ts switch case 问题
- **文件**: `admin/hidden/route.ts` (POST 方法)
- **问题**: 与 appeals/route.ts 相同的 switch case 块级作用域问题
- **状态**: ✅ 已修复

### 常见问题模式

#### switch case 块级作用域
```typescript
// ❌ 错误
switch (type) {
  case 'a':
    const a = getA();
    break;
  case 'b':
    const b = getB(); // 编译错误！
    break;
}

// ✅ 正确
switch (type) {
  case 'a': {
    const a = getA();
    break;
  }
  case 'b': {
    const b = getB();
    break;
  }
}
```

#### Prisma 事务处理
```typescript
// ✅ 正确：使用 $transaction
await prisma.$transaction([
  prisma.user.update({ ... }),
  prisma.record.delete({ ... }),
]);
```
