## 一、问题分析

### 1.1 当前存在的问题

| 问题 | 描述 | 影响 |
|------|------|------|
| **缺少面包屑导航** | 用户进入深层页面后无法快速返回上级 | 用户迷路 |
| **侧边栏层级导航缺失** | 只有顶部导航，没有当前模块的子导航 | 切换困难 |
| **返回按钮不统一** | 有些页面有返回按钮，有些没有 | 体验不一致 |
| **页面层级不清晰** | 用户不知道自己在网站中的位置 | 迷失方向 |
| **快捷键缺失** | 没有键盘快捷键支持 | 操作效率低 |
| **移动端体验差** | 深层页面没有返回机制 | 移动端用户流失 |
| **通知跳转混乱** | 通知点击后跳转目标不明确 | 用户困惑 |

### 1.2 当前页面层级结构

```
首页 (/)
├── 探索 (/explore)
├── 讨论 (/discussions)
│   ├── 讨论详情 (/discussions/[id])
│   └── 创建讨论 (/discussions/new)
├── 搜索 (/search)
├── 用户主页 (/[username])
│   └── 仓库页面 (/[username]/[repoName])
│       ├── 文件浏览 (/[username]/[repoName]/tree/[...path])
│       ├── 文件预览 (/[username]/[repoName]/blob/[...path])
│       └── 仓库设置 (/[username]/[repoName]/settings)
├── 创建仓库 (/new)
├── 设置 (/settings)
│   ├── Profile
│   ├── Account
│   ├── Notifications
│   ├── Repos
│   └── Export
└── 管理面板 (/admin)
    ├── Dashboard
    ├── Users
    ├── Repos
    ├── Discussions
```

## 二、解决方案

### 2.1 面包屑导航（核心功能）

**位置**：页面顶部，Header 下方

```
┌────────────────────────────────────────────────────────────────────┐
│ Home / 讨论 / [标题过长时截断...] / 回复 #3                        │
└────────────────────────────────────────────────────────────────────┘
```

**实现**：
```typescript
// components/layout/Breadcrumb.tsx
interface BreadcrumbItem {
  label: string;
  href?: string;
}

function Breadcrumb({ items }: { items: BreadcrumbItem[] }) {
  return (
    <nav className="breadcrumb" aria-label="面包屑导航">
      <Link href="/">首页</Link>
      {items.map((item, index) => (
        <span key={index}>
          <span className="separator">/</span>
          {item.href ? (
            <Link href={item.href}>{truncate(item.label, 20)}</Link>
          ) : (
            <span className="current">{truncate(item.label, 20)}</span>
          )}
        </span>
      ))}
    </nav>
  );
}
```

**页面配置示例**：
```typescript
// 讨论详情页
const breadcrumb = [
  { label: '讨论', href: '/discussions' },
  { label: discussion.title, href: `/discussions/${id}` },
  { label: '回复 #' + commentIndex }
];

// 仓库文件页
const breadcrumb = [
  { label: ownerUsername, href: `/${ownerUsername}` },
  { label: repoName, href: `/${ownerUsername}/${repoName}` },
  { label: 'src', href: `/${ownerUsername}/${repoName}/tree/main/src` },
  { label: 'App.tsx' }
];
```

### 2.3 统一返回按钮

**规则**：
| 场景 | 返回目标 |
|------|---------|
| 讨论详情 ← 返回 | 讨论列表（带筛选条件） |
| 仓库文件 ← 返回 | 仓库概览页面 |
| 用户主页 ← 返回 | 首页或来源页面 |
| 设置页面 ← 返回 | 用户主页 |
| 管理面板 ← 返回 | 首页 |

**实现**：
```typescript
// components/ui/BackButton.tsx
interface BackButtonProps {
  fallback?: string;  // 默认返回地址
  preserveHistory?: boolean;  // 是否使用浏览器历史
}

function BackButton({ fallback = '/', preserveHistory = false }: BackButtonProps) {
  const router = useRouter();

  const handleBack = () => {
    if (preserveHistory && window.history.length > 1) {
      router.back();
    } else {
      router.push(fallback);
    }
  };

  return (
    <button onClick={handleBack} className="back-button">
      ← 返回
    </button>
  );
}
```

**实现**：
```typescript
// hooks/useKeyboardShortcuts.ts
function useKeyboardShortcuts() {
  useEffect(() => {
    const handleKeyDown = (e: KeyboardEvent) => {
      // 忽略输入框中的按键
      if (e.target instanceof HTMLInputElement || e.target instanceof HTMLTextAreaElement) {
        return;
      }

      switch (e.key) {
        case '?':
          e.preventDefault();
          showShortcutHelp();
          break;
        case '/':
          e.preventDefault();
          focusSearchInput();
          break;
        case 'Escape':
          closeModal();
          break;
        // G + X 组合键
        case 'g':
          window.pendingKey = 'g';
          setTimeout(() => { window.pendingKey = null; }, 1000);
          break;
        // ...
      }
    };

    window.addEventListener('keydown', handleKeyDown);
    return () => window.removeEventListener('keydown', handleKeyDown);
  }, []);
}
```

### 3.1 层级定义

| 层级 | 名称 | 说明 | 导航方式 |
|------|------|------|---------|
| L0 | 首页 | 网站入口 | Header 导航 |

| L3 | 三级页面 | 深层内容 | 面包屑 + 侧边栏 |

### 3.2 导航规则

```
L0 → L1：Header 导航 / Logo
L1 → L2：内容卡片点击 / 面包屑
L2 → L3：内容内部链接
L3 → L2：返回按钮 / 面包屑
L2 → L1：面包屑 / 返回按钮
L1 → L0：Logo / 面包屑
```

## 五、技术实现要点

### 5.1 面包屑实现

```typescript
// lib/utils/breadcrumb.ts
export function generateBreadcrumbs(pathname: string, params: Record<string, string>): BreadcrumbItem[] {
  const segments = pathname.split('/').filter(Boolean);
  const breadcrumbs: BreadcrumbItem[] = [];

  // 首页
  breadcrumbs.push({ label: '首页', href: '/' });

  // 根据路径生成面包屑
  switch (segments[0]) {
    case 'discussions':
      breadcrumbs.push({ label: '讨论', href: '/discussions' });
      if (segments[1]) {
        // 讨论详情
        breadcrumbs.push({ label: `讨论 #${params.id}`, href: `/discussions/${params.id}` });
        if (segments[2]) {
          breadcrumbs.push({ label: '回复' });
        }
      }
      break;
    case '[username]':
      breadcrumbs.push({ label: params.username });
      if (segments[2]) {
        // 仓库页面
        breadcrumbs.push({ label: params.repoName, href: `/${params.username}/${params.repoName}` });
        // 文件路径
        if (segments[3]) {
          breadcrumbs.push({ label: params.path.join('/') });
        }
      }
      break;
    // ... 其他路径
  }

  return breadcrumbs;
}
```

### 5.2 路由守卫

```typescript
// middleware.ts
export function middleware(request: NextRequest) {
  // 登录状态检查
  const isAuthenticated = checkAuth(request);

  // 需要认证的页面
  const protectedRoutes = ['/settings', '/new', '/admin'];
  const isProtectedRoute = protectedRoutes.some(route =>
    request.nextUrl.pathname.startsWith(route)
  );

  if (isProtectedRoute && !isAuthenticated) {
    return NextResponse.redirect(new URL('/login', request.url));
  }

  // 管理面板权限检查
  if (request.nextUrl.pathname.startsWith('/admin')) {
    if (!isAdmin(request)) {
      return NextResponse.redirect(new URL('/', request.url));
    }
  }

  return NextResponse.next();
}
```
