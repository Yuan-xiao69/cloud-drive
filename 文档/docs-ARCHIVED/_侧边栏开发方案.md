# 首页侧边栏开发方案

## 一、需求分析

参考 GitHub 首页布局，在首页左侧添加「我的仓库」侧边栏，用于快速访问用户个人仓库列表。

## 二、技术方案

### 2.1 新增 API 端点

| 文件 | 端点 | 方法 | 功能 |
|------|------|------|------|
| `api/v1/me/repos/route.ts` | `/api/v1/me/repos` | GET | 获取当前用户仓库列表 |
| `api/v1/me/stars/route.ts` | `/api/v1/me/stars` | GET | 获取当前用户收藏列表 |
| `api/v1/me/pull-requests/route.ts` | `/api/v1/me/pull-requests` | GET | 获取待处理 PR 列表 |
| `api/v1/repos/route.ts` | `/api/v1/repos` | GET | 获取仓库列表（支持排序/分页） |

### 2.2 新增组件

| 文件 | 功能 | 说明 |
|------|------|------|
| `components/layout/LeftSidebar.tsx` | 左侧边栏 | 显示「我的仓库」列表 |
| `components/layout/RightSidebar.tsx` | 右侧边栏 | 显示「我的收藏」列表 |

### 2.3 页面改造

修改 `app/(main)/page.tsx`：
- 引入 `LeftSidebar` 和 `RightSidebar` 组件
- 仅在用户登录后显示侧边栏
- 左侧边栏固定宽度 240px，右侧边栏固定宽度 280px
- 使用 `position: sticky` 固定在视口

## 三、数据模型

### 3.1 Repo 模型

```prisma
model Repo {
  id          String   @id @default(cuid())
  name        String
  ownerId     String
  owner       User     @relation(fields: [ownerId], references: [id])
  description String?
  stars       Int      @default(0)
  forks       Int      @default(0)
  watchers    Int      @default(0)
  language    String?
  isPrivate   Boolean  @default(false)
  isHidden    Boolean  @default(false)
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
}
```

### 3.2 Star 模型

```prisma
model Star {
  id        String   @id @default(cuid())
  userId    String
  repoId    String
  createdAt DateTime @default(now())
  user      User     @relation(fields: [userId], references: [id])
  repo      Repo     @relation(fields: [repoId], references: [id])
  @@unique([userId, repoId])
}
```

## 四、API 响应格式

统一使用 `{ code, message, data }` 格式：

```typescript
{
  code: 200,
  message: "success",
  data: {
    items: [...],
    total: number,
    page: number,
    limit: number
  }
}
```

## 五、组件设计

### 5.1 LeftSidebar（左侧边栏）

```
┌─────────────────────────┐
│ 我的仓库                │
├─────────────────────────┤
│ 📁 repository-1         │
│ 📁 repository-2         │
│ 📁 repository-3         │
│ ...                     │
├─────────────────────────┤
│ [查看全部 →]            │
└─────────────────────────┘
```

**功能：**
- 显示当前用户的前 10 个仓库
- 显示仓库图标、名称
- 点击跳转到仓库页面
- 底部「查看全部」链接

### 5.2 RightSidebar（右侧边栏）

```
┌─────────────────────────┐
│ 我的收藏                │
├─────────────────────────┤
│ ⭐ awesome-project      │
│ ⭐ another-repo         │
│ ...                     │
├─────────────────────────┤
│ [查看全部 →]            │
```

**功能：**
- 显示当前用户收藏的前 10 个仓库
- 显示星标图标、仓库名称
- 点击跳转到仓库页面
- 底部「查看全部」链接

## 六、布局实现

```tsx
<div className="home-page">
  <Header />
  <div className="flex min-height">
    {/* 左侧边栏 */}
    {user && (
      <aside className="w-[240px] left-sidebar">
        <LeftSidebar />
      </aside>
    )}

    {/* 主内容 */}
    <main className="flex-1">
      <HeroSection />
      <StatsSection />
      <HotReposSection />
      <HotDiscussionsSection />
      <FeaturesSection />
    </main>

    {/* 右侧边栏 */}
    {user && (
      <aside className="w-[280px] right-sidebar">
        <RightSidebar />
      </aside>
    )}
  </div>
</div>
```

## 七、CSS 样式

所有样式放在 `globals.css` 中，使用 `.home-page` 前缀隔离：

```css
.home-page .left-sidebar {
  width: 240px;
  flex-shrink: 0;
  border-right: 1px solid var(--color-border-default);
  padding: 24px 16px;
  height: calc(100vh - 64px);
  position: sticky;
  top: 64px;
  overflow-y: auto;
}

.home-page .right-sidebar {
  width: 280px;
  flex-shrink: 0;
  border-left: 1px solid var(--color-border-default);
  padding: 24px 16px;
  height: calc(100vh - 64px);
  position: sticky;
  top: 64px;
  overflow-y: auto;
}
```

## 八、注意事项

1. **Next.js 14 App Router 不支持 `<style jsx>`**，所有样式必须放在 `globals.css` 中
2. 侧边栏仅在用户登录后显示（使用 `useAuth` hook）
3. 使用 `position: sticky` 实现滚动时侧边栏固定
4. API 路由文件必须放在正确的目录结构中
5. 清除缓存后需要重启容器：`docker exec <container> bash -c "rm -rf /app/.next" && docker restart <container>`
