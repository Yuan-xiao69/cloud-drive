一、现有管理面板功能清单
--------------------------------------------------------------------------------

1. Dashboard (仪表盘)
   - 总用户数统计
   - 今日新用户统计
   - 公开仓库数统计
   - 待处理举报数统计
   - 最新举报列表（仅显示3条）
   - 快捷操作卡片（4个入口）

2. 用户管理 (AdminUsersTab.tsx)
   - 用户列表展示
   - 用户搜索
   - 用户删除
   - 用户禁用/启用
   - 批量选择删除
   - 右键上下文菜单（禁言、限制仓库、限制存储）

3. 仓库管理 (AdminReposTab.tsx)
   - 仓库列表展示
   - 仓库搜索
   - 仓库删除
   - 仓库所有者信息
   - 语言/Star/Fork统计
   - 批量选择删除
   - 右键上下文菜单

4. 讨论管理 (AdminDiscussionsTab.tsx)
   - 讨论列表展示
   - 按分类筛选（提问/分享/讨论/Bug/建议）
   - 按状态筛选（开放中/已解决）
   - 讨论搜索
   - 讨论删除/恢复
   - 浏览量/评论数显示

5. 举报管理 (AdminReportsTab.tsx)
   - 举报列表展示
   - 举报详情查看
   - 删除被举报内容
   - 忽略举报
   - 处罚举报对象（仅超级管理员）

6. 处罚管理 (AdminPenaltiesTab.tsx)
   - 处罚列表展示
   - 处罚类型筛选（禁言/仓库限制/存储限制/封禁）
   - 处罚状态筛选（生效中/已过期/已撤销）
   - 添加处罚
   - 解除处罚
   - 封禁账号
   - 申诉记录查看

7. 申诉管理 (AdminAppealsTab.tsx)
   - 申诉列表展示
   - 申诉状态筛选（待处理/已通过/已拒绝）
   - 申诉详情查看
   - 通过/拒绝申诉
   - 管理员回复

8. IP黑名单 (AdminIpBlacklistTab.tsx)
   - IP黑名单列表
   - 添加IP到黑名单
   - IP搜索
   - 删除IP
   - 状态/过期时间显示

9. 安全事件 (AdminSecurityTab.tsx)
   - 安全事件列表
   - 按严重性筛选（严重/高/中/低）
   - 按状态筛选（待处理/已解决/已忽略）
   - 事件详情查看
   - 标记为已解决

10. 审计日志 (AdminAuditLogsTab.tsx)
    - 日志列表展示
    - 时间/用户/操作/目标类型/详情/IP显示
    - 分页浏览

11. 系统公告 (AdminAnnouncementsTab.tsx)
    - 公告列表展示
    - 公告类型（信息/警告/紧急）
    - 优先级设置（高/普通/低）
    - 启用/禁用开关
    - 置顶功能
    - 创建/编辑/删除公告

12. 通知管理 (AdminNotificationsTab.tsx)
    - 用户搜索
    - 单个/批量选择用户
    - 发送系统通知
    - 通知类型选择
    - 跳转链接设置

二、现有功能缺陷分析
--------------------------------------------------------------------------------

1. Dashboard 问题
   - [严重] 统计指标过少，无法全面了解平台状况
   - [严重] 缺乏数据可视化，无法发现趋势问题
   - [严重] 没有实时通知/警告机制
   - [中等] 快捷操作入口不完整
   - [中等] 没有活动时间线

2. 用户管理问题
   - [严重] 无法查看用户详细信息（如活跃度、贡献等）
   - [严重] 缺少角色权限管理界面
   - [严重] 没有用户批量处罚功能
   - [中等] 缺少用户高级筛选（注册时间、活跃状态等）
   - [中等] 缺少用户导出功能
   - [中等] 右键菜单功能不完整

3. 仓库管理问题
   - [严重] 无法查看仓库详细内容（如文件结构、最近提交等）
   - [严重] 缺少仓库高级筛选（语言、大小、创建时间等）
   - [中等] 没有仓库批量操作
   - [中等] 缺少仓库健康度指标
   - [低] 缺少仓库统计分析

4. 讨论管理问题
   - [中等] 缺少讨论内容搜索/全文检索
   - [中等] 没有内容审核功能
   - [中等] 缺少举报内容关联

5. 处罚/申诉问题
   - [中等] 缺少处罚模板/快速处罚
   - [中等] 没有申诉工作流管理
   - [中等] 缺少处罚效果统计

6. IP黑名单问题
   - [中等] 缺少IP地理位置显示
   - [中等] 缺少IP段管理（CIDR）
   - [中等] 没有自动封禁规则
   - [低] 缺少IP访问统计

7. 安全事件问题
   - [中等] 缺少安全仪表盘/趋势图
   - [中等] 缺少自动告警机制
   - [低] 没有安全报告生成

8. 审计日志问题
   - [中等] 缺少日志筛选/搜索
   - [中等] 缺少日志导出功能
   - [低] 没有日志统计/分析

9. 系统配置问题
   - [严重] 完全没有系统设置页面
   - [严重] 没有邮件配置管理
   - [严重] 没有备份管理
   - [中等] 没有API密钥管理
   - [中等] 没有Webhook管理

三、设计原则
--------------------------------------------------------------------------------

1. 参考标准
   - GitHub Admin Dashboard: 简洁高效、数据驱动
   - GitLab Admin Area: 模块化、层级清晰
   - Datadog: 可视化丰富、监控完善
   - Stack Overflow: 内容审核专业、工作流完善

2. 设计理念
   - 实用性优先：每个功能都要有实际价值
   - 数据驱动：提供统计、趋势、预警
   - 操作高效：支持批量操作、快捷键
   - 视觉统一：遵循现有设计系统
   - 安全优先：敏感操作多重确认
   - **页面整洁：所有操作统一集成到右键菜单，列表页面只保留核心信息和状态显示**


3. 右键菜单集成操作设计（核心理念）
--------------------------------------------------------------------------------

【设计原则】

为保持页面整洁和操作高效，所有列表页面的操作统一集成到右键上下文菜单中，
参考 GitHub 和 VS Code 的设计理念：

  GitHub 设计风格：
  - 列表行只显示关键信息和状态
  - 右键点击显示操作菜单
  - 支持多选批量操作
  - 键盘快捷键支持

  VS Code 设计风格：
  - 清晰的菜单分组
  - 图标+文字组合
  - 快捷键提示
  - 子菜单展开

【统一右键菜单规范】

┌─────────────────────────────────────────────────────────────────────────┐
│ 🎯 右键菜单通用结构                                                     │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  👁 查看详情                     ← 主要操作（第一组）                  │
│  ─────────────────────────────                                         │
│  ✏️ 编辑                    Ctrl+E │                                   │
│  📋 复制信息                     Ctrl+C │  次要操作（第二组）            │
│  ─────────────────────────────                                         │
│  🚫 禁用  │  🗑️ 删除  │  📤 导出 │  状态相关（第三组）                │
│  ─────────────────────────────                                         │
│  ⚠️ 处罚                        │  管理操作（第四组，需权限）         │
│  🔒 封禁                        │                                   │
│  ─────────────────────────────                                         │
│  ❓ 帮助                        │  辅助信息                          │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘

【菜单分组设计】

第一组 - 主要操作（总是可见）：
  - 查看详情 (Enter)
  - 在新标签页打开

第二组 - 次要操作：
  - 编辑 (E)
  - 复制信息 (Ctrl+C)
  - 复制链接

第三组 - 状态切换：
  - 启用/禁用
  - 激活/停用
  - 公开/私有

第四组 - 管理操作（需权限）：
  - 处罚...
  - 封禁...
  - 删除 (d)

第五组 - 导出/工具：
  - 导出选中项
  - 导出全部
  - 刷新数据

第六组 - 帮助：
  - 查看帮助
  - 快捷键列表

【视觉样式规范】

菜单样式：
  - 背景色: #ffffff (浅色) / #1e1e1e (深色)
  - 边框: 1px solid #d0d7de
  - 阴影: 0 8px 24px rgba(0,0,0,0.15)
  - 圆角: 6px
  - 内边距: 4px 0
  - 菜单项高度: 32px
  - 菜单最小宽度: 200px
  - 图标大小: 16px

菜单项样式：
  - 悬停背景: #f6f8fa
  - 选中背景: #0969da (主色)
  - 选中文字: #ffffff
  - 分隔线: 1px solid #d0d7de
  - 禁用项文字: #8c959f
  - 危险操作文字: #cf222e

快捷键样式：
  - 文字颜色: #57606a
  - 字体大小: 12px
  - 右对齐，距右侧 8px

【交互行为规范】

触发方式：
  - 鼠标右键单击
  - 菜单键 (Context Menu Key)
  - Shift+F10

关闭方式：
  - 点击菜单外部
  - 按下 Escape
  - 选择操作后自动关闭

子菜单：
  - 悬停到带 ▶ 的菜单项
  - 延迟 200ms 展开
  - 箭头指示方向

多选支持：
  - Ctrl+点击 多选
  - Shift+点击 范围选
  - 选中后右键显示 "对 N 项操作"

键盘导航：
  - ↑/↓ 上下移动
  - Enter 确认
  - ←/→ 展开/收起子菜单
  - 打字快速定位
