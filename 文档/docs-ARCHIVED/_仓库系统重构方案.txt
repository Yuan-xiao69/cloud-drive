# 用户需求时间：2026-04-24
# 状态：待审核

## 一、需求理解与重构目标

### 1.1 用户核心诉求

用户希望将"仓库"重构为类似 Windows 文件系统的虚拟存储空间，核心特性：

| 特性 | 描述 |
|------|------|
| 虚拟磁盘 | 仓库 = 用户的私有虚拟磁盘空间 |
| 资源管理器 | 像 Windows 一样管理文件夹和文件 |
| 在线预览 | 支持在线预览各种文件类型 |
| 权限控制 | Fork 需要申请 + 审批流程 |
| 本地上传 | 支持上传本地文件夹，无限速 |
| 在线创建 | 支持在线创建文件，改后缀 |
| 数据库存储 | 仓库数据存数据库，按用户分类 |
| 链接分享 | 生成仓库链接，分享到评论区 |
| 管理员管理 | 超级管理员全权管理 |

## 二、现有架构分析

### 2.1 当前仓库实现

```
仓库 (Repository)
├── 基本信息 (name, description, visibility)
├── Star/Watch 社交功能
├── 文件存储 (repo_items 表)
└── 讨论区 (discussions)
```

### 2.2 当前文件存储结构

```typescript
// repo_items 表
{
  id: string,
  repoId: string,
  name: string,           // 文件/文件夹名称
  type: 'file' | 'folder', // 类型
  path: string,            // 路径: /src/components/Button.tsx
  content: string,         // 文件内容（二进制存储为 base64 或文本）
  size: number,            // 文件大小
  mimeType: string,        // MIME 类型
  parentPath: string,       // 父目录路径
  isDeleted: boolean,       // 软删除
  createdAt: Date,
  updatedAt: Date
}
```

### 2.3 现有 API 端点

| 端点 | 功能 |
|------|------|
| POST /api/repos | 创建仓库 |
| GET /api/repos/[username]/[repoName]/tree | 获取文件树 |
| POST /api/repos/.../upload | 上传文件 |
| PATCH /api/repos/.../tree | 移动/重命名 |
| DELETE /api/repos/.../tree | 删除文件/文件夹 |

## 三、重构方案

### 3.1 数据库重构

#### 3.1.1 仓库表扩展 (Repository)

```prisma
model Repository {
  id              String    @id @default(cuid())
  name            String
  description     String?
  ownerId         String
  owner           User      @relation(fields: [ownerId], references: [id])

  // 新增字段
  totalSize       BigInt    @default(0)          // 仓库总大小（字节）
  maxSize         BigInt    @default(10737418240) // 最大容量：默认 10GB
  fileCount       Int       @default(0)          // 文件数量
  folderCount     Int       @default(0)          // 文件夹数量

  // 权限相关
  visibility      Int       @default(0)          // 0=私有, 1=公开, 2=需申请
  allowFork       Boolean   @default(true)       // 是否允许 Fork
  forkRequestList ForkRequest[]                   // Fork 申请列表

  // 社交功能
  stars           Star[]
  watchers        Watch[]

  // 文件树
  items           RepoItem[]

  // 讨论区
  discussions     Discussion[]

  // 元数据
  isDeleted       Boolean   @default(false)
  createdAt       DateTime  @default(now())
  updatedAt       DateTime  @updatedAt
}
```

#### 3.1.2 新增：Fork 申请表 (ForkRequest)

```prisma
model ForkRequest {
  id            String    @id @default(cuid())
  repoId        String    // 源仓库
  sourceRepo    Repository @relation(fields: [repoId], references: [id])
  requesterId   String    // 申请人
  requester     User      @relation(fields: [requesterId], references: [id])

  message       String?   // 申请留言
  status        String    @default("pending")  // pending/approved/rejected

  reviewedBy    String?   // 审批人
  reviewedAt    DateTime?
  reviewNote    String?   // 审批备注

  createdAt     DateTime  @default(now())
  updatedAt     DateTime  @updatedAt
}
```

#### 3.1.3 文件存储表扩展 (RepoItem)

```prisma
model RepoItem {
  id            String    @id @default(cuid())
  repoId        String
  repo          Repository @relation(fields: [repoId], references: [id])

  name          String    // 文件/文件夹名称（不含路径）
  type          String    // "file" | "folder"
  path          String    // 完整路径: /folder1/folder2/file.txt
  parentPath    String    // 父目录: /folder1/folder2

  // 文件特有
  content       String?   // 文本内容或 base64
  size          BigInt    @default(0)
  mimeType      String?
  extension     String?   // 文件扩展名: .txt, .js, .png
  encoding      String?   // content 编码: utf-8, base64, binary

  // 文件夹特有
  childCount    Int       @default(0)  // 子项数量

  // 版本控制
  version       Int       @default(1)
  lastCommitId  String?

  // 元数据
  isDeleted     Boolean   @default(false)
  createdAt     DateTime  @default(now())
  updatedAt     DateTime  @updatedAt
  deletedAt     DateTime?
}
```

#### 3.1.4 新增：分享链接表 (ShareLink)

```prisma
model ShareLink {
  id            String    @id @default(cuid())
  token         String    @unique  // 随机 token
  repoId        String
  repo          Repository @relation(fields: [repoId], references: [id])

  creatorId     String
  path          String?   // 指定路径，为空表示整个仓库

  // 权限
  permission    String    @default("read")  // read/download/write
  password      String?   // 可选密码保护

  // 限制
  expiresAt     DateTime? // 过期时间
  maxViews      Int?      // 最大浏览次数
  viewCount     Int       @default(0)

  isActive      Boolean   @default(true)
  createdAt     DateTime  @default(now())
}
```

#### 3.1.5 新增：文件版本表 (FileVersion)

```prisma
model FileVersion {
  id            String    @id @default(cuid())
  itemId        String
  item          RepoItem  @relation(fields: [itemId], references: [id])

  version       Int
  content       String
  size          BigInt
  message       String?   // 版本说明
  authorId      String

  createdAt     DateTime  @default(now())
}
```

## 四、功能模块设计

### 4.1 仓库管理模块

#### 4.1.1 创建仓库（虚拟磁盘）

```
POST /api/repos
{
  "name": "我的仓库",
  "description": "描述",
  "visibility": "private" | "public" | "request",  // 私有/公开/需申请

权限检查：
1. 检查用户名是否冲突
2. 检查用户是否有仓库限制 (repo_limit)
3. 检查用户存储配额
```

#### 4.1.2 仓库容量管理

```typescript
interface StorageQuota {
  totalAllowed: number;    // 用户总配额
  used: number;             // 已使用
  available: number;        // 剩余
  repoCount: number;        // 仓库数量
  repoLimits: {
    repoName: string;
    used: number;
    max: number;
  }[];
}
```

#### 4.1.3 仓库设置

```
PATCH /api/repos/[username]/[repoName]
{
  "name": "新名称",           // 可改名
  "description": "新描述",
  "visibility": "public",    // 切换可见性
  "allowFork": true,        // 是否允许 Fork

  "transferOwner": "userId" // 转让仓库（需对方同意）

```

```
    {
      "name": "src",
      "type": "folder",
      "path": "/src",
      "parentPath": "/",
      "childCount": 5,
      "size": 0,
      "updatedAt": "2024-01-01"
    },
    {
      "name": "README.md",
      "type": "file",
      "path": "/README.md",
      "parentPath": "/",
      "size": 1024,
      "mimeType": "text/markdown",
      "extension": ".md",
      "updatedAt": "2024-01-01"
    }
  ],
  "totalSize": 1024000,
  "fileCount": 25,
  "folderCount": 8
}
```

#### 4.2.2 创建文件夹（类似 Windows 右键 → 新建文件夹）

```
POST /api/repos/[username]/[repoName]/folder
{
  "name": "新建文件夹",
  "parentPath": "/src/components"
}

返回：
{
  "item": {
    "name": "新建文件夹",
    "type": "folder",
    "path": "/src/components/新建文件夹",
    "parentPath": "/src/components"
  }
}

限制检查：
1. 名称不能包含：/ \ : * ? " < > |
2. 名称长度 ≤ 255
3. 不能重名
4. 路径深度 ≤ 20 层
```

#### 4.2.3 重命名（类似 Windows F2）

```
PATCH /api/repos/[username]/[repoName]/tree
{
  "action": "rename",
  "oldPath": "/src/components/Button.tsx",
  "newName": "MyButton.tsx"
}

级联更新：
- 如果是文件夹，更新所有子项的 path 和 parentPath
- 记录操作日志
```

#### 4.2.4 移动（类似 Windows 拖拽）

```
PATCH /api/repos/[username]/[repoName]/tree
{
  "action": "move",
  "sourcePath": "/src/components/Button.tsx",
  "targetPath": "/lib/Button.tsx"
}

级联更新：
- 如果是文件夹，移动整个子树
- 检查循环引用（不能移动到自身目录下）
```

#### 4.2.5 复制（类似 Windows Ctrl+C）

```
POST /api/repos/[username]/[repoName]/copy
{
  "sourcePath": "/src/components/Button.tsx",
  "targetPath": "/lib/Button.tsx"
}
```

#### 4.2.6 删除（类似 Windows Delete）

```
DELETE /api/repos/[username]/[repoName]/tree
{
  "path": "/src/components/OldFile.tsx",
  "permanent": false  // false=放入回收站, true=永久删除
}

回收站逻辑：
- 30 天后自动清理
- 可在回收站恢复
- 永久删除立即释放空间
```

#### 4.2.7 批量操作

```
POST /api/repos/[username]/[repoName]/batch
{
  "operations": [
    { "action": "move", "source": "/a.tsx", "target": "/folder/b.tsx" },
    { "action": "delete", "path": "/c.tsx" },
    { "action": "rename", "old": "/d.tsx", "new": "/d_new.tsx" }
  ]
}
```

### 4.3 文件操作模块

#### 4.3.1 在线创建文件

```
POST /api/repos/[username]/[repoName]/file
{
  "name": "index.html",
  "parentPath": "/",
  "content": "<!DOCTYPE html>...",
  "mimeType": "text/html"
}

支持的文件类型（按扩展名）：
- 文档: .txt, .md, .doc, .docx, .pdf
- 代码: .js, .ts, .jsx, .tsx, .py, .java, .cpp, .go, .rs
- 样式: .css, .scss, .less
- 数据: .json, .xml, .yaml, .yml, .toml
- 图片: .jpg, .jpeg, .png, .gif, .svg, .webp, .ico
- 视频: .mp4, .webm, .ogg
- 音频: .mp3, .wav, .ogg
- 压缩: .zip, .tar, .gz, .rar
- 其他: .exe, .dll, .bin 等
```

#### 4.3.2 修改文件后缀

```
PATCH /api/repos/[username]/[repoName]/file
{
  "path": "/script.ts",
  "action": "changeExtension",
  "newExtension": ".js"
}

注意事项：
- 更新 mimeType
- 记录操作日志
- 通知相关用户（如果分享过）
```

#### 4.3.3 文件预览（按类型）

```
GET /api/repos/[username]/[repoName]/preview/[...path]
```

| 文件类型 | 预览方式 |
|---------|---------|
| 图片 (.jpg/.png/.gif/.svg) | 直接渲染 `<img>` |
| 文本 (.md/.txt/.json) | 代码高亮渲染 |
| 代码 (.js/.ts/.py 等) | Prism.js 代码高亮 |
| PDF | PDF.js 在线预览 |
| 视频 (.mp4/.webm) | `<video>` 播放 |
| 音频 (.mp3/.wav) | `<audio>` 播放 |
| HTML | iframe 沙箱渲染 |
| 压缩包 (.zip) | 显示文件列表 |
| 二进制 | 显示 hex dump 或"不支持预览" |

### 4.5 Fork 与权限模块

#### 4.5.1 Fork 申请流程

```
1. 用户点击 "Fork"
   ↓
2. 检查用户状态
   - 如果被禁言 (mute): 返回 403 "您已被禁言，无法发送 Fork 申请"
   - 如果被仓库限制 (repo_limit): 返回 403 "您已被限制创建仓库"
   ↓
3. 检查仓库 visibility
   - private: 禁止 Fork
   - public: 直接 Fork
   - request: 进入申请流程
   ↓
4. 申请页面
   用户填写申请留言
   ↓
5. 提交申请
   POST /api/repos/[username]/[repoName]/fork-request
   { "message": "想学习这个项目..." }
   ↓
6. 仓库所有者收到通知
   在仓库设置中看到申请列表
   ↓
7. 审批
   PATCH /api/fork-requests/[id]
   { "action": "approve" | "reject", "note": "备注" }
   ↓
8. 结果通知
   - 通过：用户获得仓库副本
   - 拒绝：通知用户并说明原因
   - 超时：申请超过 **7 天**未处理，自动标记为过期
```

#### 4.5.2 Fork 申请超时管理

| 场景 | 处理方式 |
|------|---------|
| 正常 Fork 申请 | 仓库主人自己处理，管理面板不介入 |
| 超时丢弃 | 申请超过 **7 天**未处理，自动标记为过期 |

```typescript
// 自动清理超时申请（定时任务/Cron Job）
async function cleanupExpiredForkRequests() {
  const expiredDate = new Date(Date.now() - 7 * 24 * 60 * 60 * 1000);
  
  await prisma.forkRequest.updateMany({
    where: {
      status: 'pending',
      createdAt: { lt: expiredDate }
    },
    data: {
      status: 'expired'  // expired / rejected
    }
  });
}
```

#### 4.5.3 API 端点

```
# 申请 Fork
POST /api/repos/[username]/[repoName]/fork-request

# 获取发出的申请
GET /api/fork-requests?type=sent

# 获取收到的申请（仓库所有者）
GET /api/repos/[username]/[repoName]/fork-requests

# 审批申请
PATCH /api/fork-requests/[id]
{ "action": "approve", "note": "欢迎参与" }
```

#### 4.5.4 Fork 后的关系

```
源仓库 (A)
  └── Fork 请求者 (B) 的副本仓库 (B-A)
        ├── 保留对源仓库的引用
        ├── 可同步源仓库更新
        └── Fork 的仓库也可被 Fork
```

#### 4.5.5 用户限制说明

##### 禁言 (mute)

禁言只限制以下行为：

| 行为 | 禁言后状态 |
|------|-----------|
| ❌ 发送 Fork 申请 | 禁止申请 Fork 他人仓库 |
| ❌ 发送讨论 | 禁止发布新讨论 |
| ✅ 发表评论 | 允许 |
| ✅ 浏览公开内容 | 允许 |
| ✅ Star/Watch | 允许 |
| ✅ 操作自己的仓库 | 允许 |

##### 仓库限制 (repo_limit)

| 行为 | 限制后状态 |
|------|-----------|
| ❌ 创建仓库 | 禁止 |
| ❌ Fork 仓库 | 禁止 |
| ✅ 访问公开仓库 | 允许 |
| ✅ 评论/讨论 | 允许 |
| ✅ 上传文件到自己仓库 | 禁止 |

##### 存储限制 (storage_limit)

| 行为 | 限制后状态 |
|------|-----------|
| ❌ 上传文件 | 禁止 |
| ❌ 创建仓库（超过配额） | 禁止 |
| ✅ 浏览和下载 | 允许 |

## 七、存储方案

### 7.1 数据库存储策略

| 内容 | 存储方式 |
|------|---------|
| 小文件 (< 1MB) | 直接存数据库 `content` 字段 |
| 大文件 (> 1MB) | 存 MinIO，返回路径 |
| 文件元数据 | 数据库 `repo_items` 表 |
| 二进制文件 | MinIO 对象存储 |

### 7.2 存储配额

```typescript
interface StorageQuota {
  // 默认配额
  defaultQuota: 10 * 1024 * 1024 * 1024,  // 10GB

  // 用户等级配额
  tiers: {
    free: 1 * 1024 * 1024 * 1024,      // 1GB
    basic: 10 * 1024 * 1024 * 1024,    // 10GB
    pro: 100 * 1024 * 1024 * 1024,    // 100GB
    enterprise: -1,                     // 无限制
  }
}
```

### 7.3 容量计算

```sql
-- 用户存储使用统计
SELECT
  u.id,
  u.username,
  SUM(CAST(r.totalSize AS BIGINT)) as totalUsed,
  COUNT(r.id) as repoCount
FROM users u
JOIN repositories r ON u.id = r.ownerId
WHERE r.isDeleted = false
GROUP BY u.id, u.username;
```

## 十一、通知系统规范

### 11.2 全局公告横幅规范

```
┌────────────────────────────────────────────────────────────────────┐
│ 🏛️ [重要] 系统将于今晚 22:00-24:00 进行维护，届时服务不可用。      │
```

| 公告级别 | 颜色 | 用途 |
|---------|------|------|
| `critical` | 🔴 红色 | 紧急停服、安全问题 |
| `warning` | 🟡 黄色 | 重要提醒、功能变更 |
| `info` | 🔵 蓝色 | 一般公告 |

| 优先级 | 标识 | 显示方式 | 声音 |
|--------|------|---------|------|

| `high` | 🟠 | 横幅 + 列表置顶 | ❌ |
| `normal` | 🔵 | 仅列表 | ❌ |
| `low` | ⚪ | 仅列表（折叠） | ❌ |
