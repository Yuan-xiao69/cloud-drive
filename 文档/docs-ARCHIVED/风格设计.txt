一、现有UI结构概览
--------------------------------------------------------------------------------

1. Header (Header.tsx)
   - Logo + 品牌名称
   - 导航链接（讨论、探索）
   - 搜索框（居中）
   - 用户操作区域（通知、主题切换、用户菜单）
   - 公告弹窗
   - 实时通知 SSE 连接

2. LeftSidebar (LeftSidebar.tsx)
   - 我的仓库列表（最多8个）
   - 待处理 PR 列表
   - 宽度固定 256px (w-64)
   - 独立于主布局

3. RightSidebar (RightSidebar.tsx)
   - 我的收藏列表（最多10个）
   - 宽度固定 256px (w-64)
   - 独立于主布局

4. MainLayout (MainLayout.tsx)
   - 左侧边栏（集成在布局中）
   - 主内容区
   - 可控制显示/隐藏

5. 用户个人页面 (UserProfileClient.tsx)
   - 用户头像 + 信息
   - Tab 导航（概览/仓库/讨论/收藏）
   - 概览：左侧热门仓库 + 右侧个人详情
   - 使用内联样式

6. 设置页面 (settings/page.tsx)
   - 左侧设置导航
   - 右侧设置内容
   - 使用类名样式

二、现有问题分析
--------------------------------------------------------------------------------

【Header 问题】
- [中等] Logo 区域占用空间较大
- [中等] 移动端菜单体验可优化
- [低] 通知下拉菜单可增强

【侧边栏问题】
- [严重] LeftSidebar 和 RightSidebar 独立于 MainLayout，布局不一致
- [严重] 侧边栏在移动端完全隐藏，用户无法快速访问自己的仓库
- [中等] 侧边栏样式与主内容区域视觉分离
- [中等] 侧边栏数据加载时显示骨架屏不够统一

【用户个人页面问题】
- [严重] 使用大量内联样式，与其他页面风格不一致
- [中等] 布局结构不够清晰
- [中等] 信息层级不够明显
- [中等] Tab 导航位置不够突出

【设置页面问题】
- [中等] 样式使用类名，与用户页面不一致
- [低] 设置项分组可以更清晰

【整体风格问题】
- [中等] 不同页面使用不同的样式方式（内联、类名、Tailwind）
- [低] 部分组件的深色模式适配不一致

三、设计目标
--------------------------------------------------------------------------------

1. **统一性**：整个网站使用一致的布局模式和样式规范
2. **简洁性**：参考 GitHub，保持界面简洁高效
3. **可用性**：优化交互流程，提升用户体验
4. **响应式**：支持桌面端和移动端
5. **一致性**：保持 Light/Dark 模式视觉一致

四、GitHub 布局参考
--------------------------------------------------------------------------------

GitHub 的核心布局模式：
┌────────────────────────────────────────────────────────────────────────────┐
│                        Header (固定顶部，高度 64px)                        │
├────────────────────────────────────────────────────────────────────────────┤
│                                                                            │
│  ┌──────────────────────────────────────────────────────────────────────┐ │
│  │                     主内容区域 (flex-1)                               │ │
│  │                                                                      │ │
│  │   [可选侧边栏]  │           主要内容              │  [可选侧边栏]   │ │
│  │                 │                                  │                 │ │
│  └──────────────────────────────────────────────────────────────────────┘ │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘

关键特点：
- 侧边栏宽度固定（通常 280px 或 320px）
- 主内容区使用最大宽度限制（通常 1280px）
- 侧边栏可折叠/可隐藏
- 移动端侧边栏通常隐藏或变为底部导航

5.2 布局容器设计

【AppContainer 组件】
- 全局布局容器，管理 Header、侧边栏、主内容区
- 接收侧边栏配置参数
- 统一处理响应式逻辑

【布局类型】
- type LayoutType = 'full' | 'with-left-sidebar' | 'with-right-sidebar' | 'with-both-sidebars' | 'centered'

【响应式断点】
- Desktop: >= 1280px (显示所有侧边栏)
- Tablet: 768px - 1279px (隐藏右侧边栏)
- Mobile: < 768px (隐藏所有侧边栏，显示移动端底部导航)


六、Header 优化设计
--------------------------------------------------------------------------------

6.1 当前 Header 结构分析

当前 Header 包含：
- Logo 区域
- 导航链接
- 搜索框
- 通知铃铛
- 创建按钮
- 主题切换
- 用户下拉菜单

6.2 优化后的 Header 设计

┌────────────────────────────────────────────────────────────────────────────┐
│ Logo │ 导航 │   │   搜索框 (居中，可伸缩)   │   │ 通知 │ 创建 │ 用户   │
└────────────────────────────────────────────────────────────────────────────┘

【优化要点】

1. Logo 区域优化
   - Logo 尺寸：32x32px
   - 品牌名称在桌面端显示，移动端隐藏
   - 高度保持 64px

2. 导航链接优化
   - 桌面端：水平排列讨论、探索等
   - 移动端：合并到汉堡菜单

3. 搜索框优化
   - 默认显示紧凑模式（搜索图标 + 快捷键提示）
   - 聚焦时展开为完整输入框
   - 支持 Cmd/Ctrl + K 全局快捷键打开
   - 搜索建议下拉

4. 通知区域优化
   - 铃铛图标 + 未读数量徽章
   - 点击展开通知面板
   - 支持标记全部已读

5. 用户菜单优化
   - 头像 + 下拉箭头
   - 下拉菜单包含：个人资料、设置、管理面板（权限）、退出

6. 移动端 Header
   ┌────────────────────────────────────────────────────────────────────────┐
   │ ☰ Logo  │   🔍   │  🔔  👤                                            │
   └────────────────────────────────────────────────────────────────────────┘
   - 汉堡菜单打开侧边抽屉

【优化要点】

1. 视觉分层
   - 区域分隔使用细线（1px border）
   - 分组标题使用小字号 + 颜色区分
   - 不同区域之间适当留白

2. 仓库列表优化
   - 显示仓库图标（公共/私有/Fork）
   - 支持拖拽排序
   - 悬停显示操作菜单（右键）
   - 超出8个显示"查看全部"

3. 待处理列表优化
   - 显示数量徽章
   - PR 显示源仓库和标题摘要
   - 过期高亮提示

4. 快捷操作入口
   - 新建仓库（主按钮样式）
   - 创建讨论（次要样式）
   - 与主 Header 的"创建"按钮功能一致

5. 响应式处理
   - 桌面端：固定显示
   - 平板端：可折叠
   - 移动端：隐藏，触发按钮显示

6. 技术实现示例
   ```tsx
   // StarredReposSidebar.tsx
   'use client';
   
   import { useState } from 'react';
   import { RepoCard } from './RepoCard';
   import { RepoContextMenu } from './RepoContextMenu';
   import { FavoriteStats } from './FavoriteStats';
   import { SearchInput } from '@/components/ui';
   import styles from './StarredReposSidebar.module.css';
   
   interface StarredReposSidebarProps {
     repos: StarredRepo[];
     stats: FavoriteStats;
   }
   
   export function StarredReposSidebar({ repos, stats }: StarredReposSidebarProps) {
     const [searchQuery, setSearchQuery] = useState('');
     const [sortBy, setSortBy] = useState<'time' | 'stars' | 'name'>('time');
     const [contextMenu, setContextMenu] = useState<ContextMenuState | null>(null);
   
     const filteredRepos = repos
       .filter(repo => repo.name.toLowerCase().includes(searchQuery.toLowerCase()))
       .sort((a, b) => {
         if (sortBy === 'stars') return b.stargazers - a.stargazers;
         if (sortBy === 'name') return a.name.localeCompare(b.name);
         return new Date(b.starredAt).getTime() - new Date(a.starredAt).getTime();
       });
   
     return (
       <aside className={styles.sidebar}>
         <div className={styles.header}>
           <h3 className={styles.title}>
             <StarIcon className={styles.icon} />
             我的收藏 ({repos.length})
           </h3>
         </div>
   
         <SearchInput
           placeholder=\"搜索收藏...\"
           value={searchQuery}
           onChange={setSearchQuery}
           className={styles.search}
         />
   
         <SortDropdown value={sortBy} onChange={setSortBy} />
   
         <div className={styles.repoList}>
           {filteredRepos.map(repo => (
             <RepoCard
               key={repo.fullName}
               repo={repo}
               onContextMenu={(e) => setContextMenu({ x: e.clientX, y: e.clientY, repo })}
             />
           ))}
         </div>
   
         <FavoriteStats stats={stats} />
   
         {contextMenu && (
           <RepoContextMenu
             repo={contextMenu.repo}
             position={contextMenu}
             onClose={() => setContextMenu(null)}
           />
         )}
       </aside>
     );
   }
   ```

13.1 样式使用优先级

1. **Tailwind CSS**（推荐）
   - 用于所有可复用的样式
   - 遵循 GitHub 颜色变量

2. **CSS 变量**（定义在 globals.css）
   - 主题颜色
   - 间距
   - 圆角
   - 阴影

3. **组件样式**（CSS Modules 或 styled-components）
   - 复杂的组件样式
   - 避免样式冲突

4. **内联样式**（不推荐，仅用于动态值）
   - 仅用于需要 JS 计算的动态样式

13.2 GitHub 颜色变量使用

所有颜色应使用 CSS 变量：
- 背景：var(--color-bg-default), var(--color-bg-subtle)
- 文字：var(--color-fg-default), var(--color-fg-muted)
- 边框：var(--color-border-default)
- 强调：var(--color-accent-fg)
- 成功：var(--color-success-fg)
- 危险：var(--color-danger-fg)

13.3 间距规范

- xs: 4px (space-1)
- sm: 8px (space-2)
- md: 16px (space-4)
- lg: 24px (space-6)
- xl: 32px (space-8)
- 2xl: 48px (space-12)

13.4 圆角规范

- sm: 4px (radius-sm)
- md: 6px (radius-md) - 默认
- lg: 8px (radius-lg)
- full: 9999px (圆形)
