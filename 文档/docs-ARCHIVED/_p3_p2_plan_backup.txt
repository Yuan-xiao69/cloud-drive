### Fork 申请超时管理
**说明**：正常的 Fork 申请由仓库主人自己处理，管理面板不介入

| 场景 | 处理方式 |
|------|---------|
| 正常 Fork 申请 | 仓库主人自己处理，管理面板不介入 |
| 超时丢弃 | 申请超过 **7 天**未处理，自动标记为过期 |

```typescript
// 自动清理超时申请（定时任务/Cron Job）
async function cleanupExpiredForkRequests() {
  const expiredDate = new Date(Date.now() - 7 * 24 * 60 * 60 * 1000);
  
  await prisma.forkRequest.updateMany({
    where: {
      status: 'pending',
      createdAt: { lt: expiredDate }
    },
    data: {
      status: 'expired'
    }
  });
}
```

## 九、用户限制功能（2026-04-24 新增）

### 功能概述
通过处罚系统实现对用户的精细化限制，支持禁言、仓库限制、存储限制三种类型。

### 限制检查工具
**文件**：`src/lib/user-restrictions.ts`

| 函数 | 功能 |
|------|------|
| `isUserMuted(userId)` | 检查用户是否被禁言 |
| `isUserRepoLimited(userId)` | 检查用户是否被限制创建仓库 |
| `isUserStorageLimited(userId)` | 检查用户是否被限制存储 |
| `getActivePenalties(userId)` | 获取用户所有生效中的处罚 |
| `checkUserRestrictions(userId)` | 综合检查所有限制 |

### API 集成限制检查

| API 文件 | 检查类型 | 被限制时的行为 |
|---------|---------|--------------|
| discussions/route.ts POST | 禁言检查 | 返回 403：创建讨论被禁止 |
| repos/route.ts POST | 仓库限制 | 返回 403：创建仓库被禁止 |
| repos/[username]/[repoName]/fork-request/route.ts POST | 禁言检查 | 返回 403：Fork 申请被禁止 |
| repos/[username]/[repoName]/fork/route.ts POST | 仓库限制 | 返回 403：Fork 仓库被禁止 |
| repos/[username]/[repoName]/upload/route.ts POST | 存储限制 | 返回 403：上传文件被禁止 |

### 限制类型详解

| 类型 | 标识 | 限制内容 | 适用场景 |
|------|------|---------|---------|
| 禁言 | mute | 禁止 Fork 申请、禁止发布讨论 | 发布违规内容、恶意攻击 |
| 仓库限制 | repo_limit | 禁止创建仓库、禁止 Fork | 传播违规内容、恶意 Fork |
| 存储限制 | storage_limit | 限制上传文件和仓库大小 | 滥用存储资源 |

### 禁言详细说明

禁言只限制以下行为：

| 行为 | 禁言后状态 |
|------|-----------|
| ❌ 发送 Fork 申请 | 禁止申请 Fork 他人仓库 |
| ❌ 发送讨论 | 禁止发布新讨论 |
| ✅ 发表评论 | 允许 |
| ✅ 浏览公开内容 | 允许 |
| ✅ Star/Watch | 允许 |
| ✅ 操作自己的仓库 | 允许 |

### 仓库限制详细说明

| 行为 | 限制后状态 |
|------|-----------|
| ❌ 创建仓库 | 禁止 |
| ❌ Fork 仓库 | 禁止 |
| ✅ 访问公开仓库 | 允许 |
| ✅ 评论/讨论 | 允许 |
| ✅ 上传文件到自己仓库 | 禁止 |

### 处罚期限

| 期限类型 | 说明 | 示例 |
|---------|------|------|
| 临时处罚 | 指定结束时间 | 7 天禁言 |
| 永久处罚 | endDate = null | 永久封禁 |

### 管理面板用户右键菜单

在 **用户管理 Tab** 中右键点击用户，新增三个快捷操作：

| 按钮 | 功能 | 限制内容 |
|------|------|---------|
| 🔇 禁言此用户 | 打开处罚模态框，预填 `mute` 类型 | 禁止 Fork 申请和发布讨论 |
| 📦 限制仓库创建 | 打开处罚模态框，预填 `repo_limit` 类型 | 禁止创建和 Fork 仓库 |
| 💾 限制存储空间 | 打开处罚模态框，预填 `storage_limit` 类型 | 限制上传文件和仓库大小 |

1. **数据库同步**：修改 schema 后执行 `docker cp prisma/schema.prisma <container>:/app/prisma/` + `prisma db push` + `prisma generate`
