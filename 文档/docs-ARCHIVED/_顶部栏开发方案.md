# 顶部栏（Header）开发方案

## 一、需求分析

参考 GitHub 顶部导航栏设计，实现统一的顶部栏组件，包含 Logo、导航链接、搜索框、通知、用户菜单等功能。

## 二、技术方案

### 2.1 组件结构

文件：`components/layout/Header.tsx`

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ [Logo] [讨论] [探索]          [搜索框]        [+] [🔔] [主题] [用户▼]  │
│  └─ header-left ─┘          └─ header-center ─┘    └─ header-right ──┘   │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 2.2 布局分区

| 区域 | 类名 | 说明 |
|------|------|------|
| 左侧 | `header-left` | Logo + 导航链接（讨论、探索） |
| 中间 | `header-center` | 搜索框（居中显示） |
| 右侧 | `header-right` | 操作按钮（创建、通知、主题、用户） |

### 2.3 功能模块

| 功能 | 组件 | 说明 |
|------|------|------|
| Logo | `LogoIcon` | GitHub 风格 Logo SVG |
| 导航 | `header-nav` | 讨论、探索链接 |
| 搜索 | `header-search` | 搜索仓库、讨论 |
| 创建 | `PlusIcon` | 创建仓库按钮 |
| 通知 | `BellIcon` + `notification-badge` | 通知图标 + 未读数 |
| SSE状态 | `WifiIcon`/`WifiOffIcon`/`RefreshIcon` | 实时通知连接状态 |
| 主题切换 | `SunIcon`/`MoonIcon` | 深色/浅色模式切换 |
| 用户菜单 | `header-avatar-btn` + `dropdown-menu` | 用户头像 + 下拉菜单 |

## 七、注意事项

1. **CSS 变量**：使用 `--color-*`、`--shadow-*`、`--radius-*` 等 CSS 变量保持一致性
2. **Tailwind CSS**：组件中可使用 Tailwind 类名，globals.css 已引入 `@tailwind` 指令
3. **SSE 连接状态**：实时通知连接状态指示器（WIFI 图标）
4. **移动端适配**：汉堡菜单、搜索框折叠、导航折叠
