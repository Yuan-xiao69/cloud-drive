### 举报目标类型

系统支持以下举报目标类型：

| 类型 | targetType | 说明 |
|------|-----------|------|
| 用户 | `user` | 举报用户 |
| 讨论 | `discussion` | 举报讨论 |
| Issue | `issue` | 举报 Issue |
| Pull Request | `pullrequest` | 举报 PR |
| 评论 | `comment` | 举报评论 |
| 仓库 | `repository` | 举报仓库 |

### 举报原因选项

| 值 | 标签 | 说明 |
|----|------|------|
| `spam` | 垃圾信息 | 发送垃圾信息 |
| `abuse` | 辱骂骚扰 | 进行辱骂或骚扰 |
| `inappropriate` | 不当内容 | 包含不当内容 |
| `copyright` | 侵权内容 | 侵犯版权 |
| `fraud` | 欺诈钓鱼 | 欺诈或钓鱼 |
| `other` | 其他原因 | 其他原因 |

## API 接口

### 举报 API

**POST /api/v1/reports** - 提交举报

请求参数：
```json
{
  "targetType": "discussion",
  "targetId": "xxx",
  "reason": "spam",
  "description": "可选的详细说明"
}
```

响应：
```json
{
  "code": 201,
  "message": "举报提交成功",
  "data": {
    "reportId": "xxx"
  }
}
```

**GET /api/v1/reports** - 获取举报记录

查询参数：
- `page`: 页码
- `pageSize`: 每页数量
- `status`: 状态筛选（pending/resolved/dismissed）

### 屏蔽 API

**POST /api/v1/me/blocks** - 屏蔽用户

请求参数：
```json
{
  "userId": "xxx",
  "reason": "可选的屏蔽原因"
}
```

**GET /api/v1/me/blocks** - 获取屏蔽列表

查询参数：
- `page`: 页码
- `pageSize`: 每页数量

**DELETE /api/v1/me/blocks?userId=xxx** - 取消屏蔽

## 设计原则

### 视觉设计

1. **举报按钮样式**：
   - 灰色边框按钮，不抢占主视觉
   - 鼠标悬停时变为红色
   - 使用旗帜图标（SVG）

2. **位置策略**：
   - 讨论/Issue/PR 详情页：标题右侧
   - 评论区：操作按钮区域
   - 仓库页面：操作菜单中

### 交互设计

1. **条件渲染**：
   - 必须登录后才能举报
   - 不能举报自己的内容
   - 举报者不能是内容作者

2. **成功反馈**：
   - 举报成功后显示成功提示
   - 1.5秒后自动关闭弹窗

3. **错误处理**：
   - 网络错误提示
   - 重复举报提示
   - 目标不存在提示

## 技术实现

### ReportModal 组件

```tsx
interface ReportModalProps {
  targetType: string;
  targetId: string;
  targetTitle?: string;
  onClose: () => void;
}
```

特点：
- 支持所有举报类型
- 单选举报原因
- 可选详细说明
- 自动获取认证 Token
- 举报成功后自动关闭

### ActionMenu 组件

```tsx
interface ActionMenuProps {
  type: 'discussion' | 'issue' | 'pullrequest' | 'comment' | 'repository';
  targetId: string;
  targetTitle?: string;
  children?: React.ReactNode;
  align?: 'left' | 'right';
}
```

特点：
- 三点菜单样式
- 点击展开下拉菜单
- 包含举报选项
- 支持自定义对齐方向

## 数据库模型

### Report 表（Prisma）

```prisma
model Report {
  id          String   @id @default(cuid())
  reporterId  String
  targetType  String
  targetId    String
  reason      String
  status      String   @default("pending")
  handlerNote String?
  createdAt   DateTime @default(now())
  handledAt   DateTime?

  reporter User @relation(fields: [reporterId], references: [id])
}
```

### Block 表（Prisma）

```prisma
model Block {
  id        String   @id @default(cuid())
  blockerId String
  blockedId String
  reason    String?
  createdAt DateTime @default(now())

  blocker User @relation(fields: [blockerId], references: [id])
  blocked User @relation(fields: [blockedId], references: [id])
}
```

## 安全性

1. **认证要求**：所有举报操作需要登录
2. **速率限制**：每小时最多 10 次举报
3. **参数验证**：严格验证 targetType 和 reason
4. **防重复**：同一用户对同一目标只能提交一次举报
5. **目标验证**：举报前检查目标是否存在
