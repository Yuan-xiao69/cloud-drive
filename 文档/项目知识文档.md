# 项目知识文档

> 类似 GitHub 的仓库式知识托管与交流平台  
> 生成日期：2026-04-28

---

## 一、项目概述

### 技术栈
| 层级 | 技术 |
|------|------|
| 框架 | Next.js 14 App Router |
| 语言 | TypeScript |
| 样式 | Tailwind CSS |
| 数据库 | PostgreSQL |
| 缓存 | Redis |
| 对象存储 | MinIO (S3 兼容) |
| ORM | Prisma 5.22.0 |
| 认证 | JWT (access_token + refresh_token) |
| 包管理 | npm |

### 运行方式
```bash
npm run dev        # 开发服务器，端口 3000/3001
NEXT_PUBLIC_USE_MOCK=true  # Mock 模式启动
```

### Docker 配置
- PostgreSQL：端口 5432，数据库 `github_platform`
- Redis：端口 6379
- MinIO：端口 9000 (API) / 9001 (Console)

## 三、数据模型（Prisma Schema）

共 **38 个模型**，关系概览：

### 3.1 核心模型

| 模型 | 说明 | 关键字段 |
|------|------|----------|
| **User** | 用户 | id, uid(9位), username, email, passwordHash, role(user/admin/super_admin), isBanned, mfaEnabled, avatarUrl, bio, location, website, deletedAt |
| **Repository** | 仓库 | id, ownerId, name, description, visibility(0私有/1公开), defaultBranch, isFork, forkedFromId, starCount, forkCount, watchCount, viewCount, language, isLocked, isArchived, deletedAt |
| **Branch** | 分支 | id, repoId, name, isDefault |
| **RepoItem** | 仓库文件/文件夹 | id, repoId, branchId, parentId, name, type, content, fileHash, fileSize(BigInt), mimeType, storagePath, linkUrl, isDeleted, depth, path, sortOrder, hash, deletedAt, deletedBy |
| **FileVersion** | 文件版本历史 | id, fileId, version, content, fileHash, fileSize, changeSize, message |
| **RepoFileChunk** | 分片上传记录 | id, repoId, branchId, uploadId, chunkIndex, chunkHash, chunkData(base64), chunkSize, totalChunks, fileName, parentPath, totalSize, mimeType, userId, status(pending/completed/failed), expiresAt |
| **Star** | 收藏 | userId + repoId (unique) |
| **Watcher** | 关注(仓库) | userId + repoId (unique) |
| **UserFollow** | 用户关注 | followerId + followingId (unique) |
| **UserBlock** | 用户屏蔽 | blockerId + blockedId (unique) |

### 3.2 讨论系统

| 模型 | 说明 | 关键字段 |
|------|------|----------|
| **Discussion** | 讨论 | id, authorId, title, content, category, status(open/closed), viewCount, isDeleted |
| **DiscussionComment** | 讨论评论 | id, discussionId, authorId, content, parentId(自引用), isAccepted, isDeleted |
| **DiscussionLike** | 讨论点赞 | discussionId + userId (unique) |

### 3.3 Issue / PR 系统

| 模型 | 说明 | 关键字段 |
|------|------|----------|
| **Issue** | Issue | id, repositoryId, authorId, title, content, status(open/closed), isDeleted |
| **IssueComment** | Issue 评论 | id, issueId, authorId, content, isDeleted |
| **IssueLabel** | Issue 标签 | id, issueId, name, color |
| **PullRequest** | PR | id, repositoryId, authorId, title, content, status(open/closed/merged), sourceBranch, targetBranch, sourceRepoId, isDeleted |
| **PullRequestComment** | PR 评论 | id, pullRequestId, authorId, content, isDeleted |

### 3.4 管理后台

| 模型 | 说明 | 关键字段 |
|------|------|----------|
| **UserBan** | 封禁记录 | userId, bannerId, reason, banType(permanent/temporary), expiresAt, isActive |
| **UserPenalty** | 处罚记录 | userId, penaltyType(mute/repo_limit/storage_limit), reason, value, appliedBy, isActive, expiresAt |
| **PenaltyTemplate** | 处罚模板 | name, penaltyType, defaultDuration, reason, usageCount, isActive |
| **PenaltyNote** | 处罚备注 | penaltyId, content, createdBy |
| **Appeal** | 申诉记录 | userId, appealType(ban/hidden/penalty), targetId, content, status(pending/approved/rejected), reviewerId |
| **Report** | 举报 | reporterId, targetType, targetId, reason, status(pending/resolved/dismissed), handlerId, handlerNote |
| **AdminAuditLog** | 审计日志 | adminId, userId, actionType, targetType, targetId, details(Json), ipAddress |
| **HiddenContent** | 隐藏内容 | targetType, targetId, reason, hiddenBy, isActive |
| **SecurityEvent** | 安全事件 | eventType, severity(info/warning/critical), userId, ipAddress, status(open/investigated/resolved/false_positive) |
| **IPBlacklist** | IP 黑名单 | ipAddress, ipRange(CIDR), reason, eventId, addedBy, expiresAt, isActive |
| **Announcement** | 系统公告 | title, content, type(info/warning/critical), priority(low/normal/high/urgent), isActive, isPinned, publishedAt, expiresAt |
| **SystemConfig** | 系统配置 | key(id), value(Text), description |

### 3.5 通知 & 其他

| 模型 | 说明 | 关键字段 |
|------|------|----------|
| **Notification** | 通知 | userId, senderId, type, title, content, linkUrl, priority(urgent/high/normal/low), isRead |
| **LoginHistory** | 登录历史 | userId, ipAddress, userAgent, success |
| **PasswordReset** | 密码重置 | userId, email, code(6位), expiresAt, used |
| **ShareLink** | 分享链接 | token(unique), repoId, creatorId, path, permission(read/download), password(bcrypt), expiresAt, maxViews, viewCount, isActive |
| **ForkRequest** | Fork 申请 | repoId, requesterId, message, status(pending/approved/rejected/expired), note, processedBy, expiresAt |
| **ApiKey** | API 密钥 | userId, name, keyHash, keyPrefix, scopes[], expiresAt, lastUsedAt, lastIp, isActive |
| **Webhook** | Webhook 配置 | repoId(可null=全局), userId, name, url, secret, contentType, events[], isActive, lastTriggeredAt, lastStatus |
| **WebhookDelivery** | Webhook 投递记录 | webhookId, event, payload, response, statusCode, duration, success, error |
| **UserActivityLog** | 用户操作日志 | userId, action, targetType, targetId, targetName, details(Json), ipAddress, userAgent, fileSize, status, errorMsg |
