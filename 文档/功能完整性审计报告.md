## 二、完整完成的功能（12 项）

### 1. 页面清单
全部 17 个需求页面均存在且功能完整。额外还有 forgot-password、reset-password、repos、new、share/[token]、issues/[id] 共 6 个页面。

### 2. 仓库页面核心功能
- Code Tab（文件列表、面包屑、侧边栏、右键菜单、拖拽上传）
- Issues Tab（创建/查看/状态筛选）
- Pull Requests Tab（创建/查看/状态筛选）
- Settings Tab（仓库编辑/删除/可见性设置）
- 分支选择器 + 分支创建

### 3. 文件预览增强
- 代码高亮（highlight.js CDN + highlightBasic 本地双引擎）

- RAW 视图
- Markdown 渲染 + DOCX 渲染（mammoth）
- XSS 安全（sanitizeHtml 包裹所有 dangerouslySetInnerHTML）

### 4. 分片上传系统

### 5. Fork 系统

### 6. 分享系统

### 7. 通知系统
- SSE 实时推送（EventSource + 自动重连 5 秒）

### 8. 举报系统
- ActionMenu 统一举报入口（type: discussion/issue/pullrequest/comment/repository）
- ReportModal 举报弹窗（6 种原因 + 详细说明，含 user 类型）
- 已接入场景：仓库页面、讨论列表、Issue 详情、PR 详情、讨论详情、**评论**（CommentSection.tsx 内嵌 ReportModal + Report 按钮）

- 用户主页举报（UserProfileClient.tsx 内嵌 ReportModal）

### 9. 安全体系
- XSS 防护（DOMPurify + sanitizeHtml + sanitizeMarkdown）
- CSRF 保护（Token 生成/验证 + Origin 验证 + 白名单）
- 速率限制（6 种类型 + 内存/Redis 双实现）
- MFA 两步验证（TOTP + 二维码 + 恢复码）

- 敏感操作验证配置
- **Magic Bytes 文件头验证**（file-validator.ts，支持 JPEG/PNG/GIF/WebP/SVG/PDF/ZIP 等 9 种格式，MIME 跨校验 + SVG 恶意脚本扫描）
