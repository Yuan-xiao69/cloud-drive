## 核心功能

### 1. 仓库系统

#### 虚拟磁盘架构
```
仓库 (Repository)
├── 基本信息 (name, description, visibility)
├── 资源配额 (totalSize, maxSize, fileCount)
├── Star/Watch 社交功能
├── 文件存储 (repo_items 表)
├── Fork 申请+审批流程
└── 讨论区 (discussions)
```

#### 文件操作
| 操作 | API | 说明 |
|------|-----|------|
| 创建文件夹 | POST `/api/repos/[name]/tree` | type='folder' |
| 上传文件 | POST `/api/repos/[name]/upload` | 分片上传支持 |
| 重命名 | PATCH `/api/repos/[name]/tree` | { op: 'rename' } |
| 移动 | PATCH `/api/repos/[name]/tree` | { op: 'move' } |
| 删除 | DELETE `/api/repos/[name]/tree` | 软删除 |

#### 文件预览
- **图片**: jpg/png/gif/webp/svg
- **PDF**: iframe 或 pdf.js
- **Markdown**: 实时渲染 + 代码块高亮
- **代码**: 大文件分页加载（500行/页）+ highlight.js

### 2. Fork 申请流程

```
用户点击 Fork → 创建申请记录 → 通知仓库主人
    ↓                                    ↓
仓库主人收到 SSE 通知              仓库主人审批页面
    ↓                                    ↓
批准 → 执行 fork → 通知结果      拒绝 → 通知结果
```

#### 数据库模型
```prisma
model ForkRequest {
  id          String    @id @default(cuid())
  repoId      String
  requesterId String
  message     String?
  status      String    @default("pending")  // pending/approved/rejected
  reviewedBy  String?
  reviewedAt  DateTime?
  reviewNote  String?
  createdAt   DateTime  @default(now())
}
```

### 3. 举报系统

#### 举报目标类型
| 类型 | targetType | 说明 |
|------|-----------|------|
| 用户 | `user` | 举报用户 |
| 讨论 | `discussion` | 举报讨论 |
| Issue | `issue` | 举报 Issue |
| Pull Request | `pullrequest` | 举报 PR |
| 评论 | `comment` | 举报评论 |
| 仓库 | `repository` | 举报仓库 |

#### 举报原因选项
| 值 | 标签 | 说明 |
|----|------|------|
| `spam` | 垃圾信息 | 发送垃圾信息 |
| `abuse` | 辱骂骚扰 | 进行辱骂或骚扰 |
| `inappropriate` | 不当内容 | 包含不当内容 |
| `copyright` | 侵权内容 | 侵犯版权 |
| `fraud` | 欺诈钓鱼 | 欺诈或钓鱼 |
| `other` | 其他原因 | 其他原因 |

#### 数据库模型
```prisma
model Report {
  id          String   @id @default(cuid())
  reporterId  String
  targetType  String
  targetId    String
  reason      String
  description String?
  status      String   @default("pending")
  handlerNote String?
  createdAt   DateTime @default(now())
  handledAt   DateTime?
}

model Block {
  id        String   @id @default(cuid())
  blockerId String
  blockedId String
  reason    String?
  createdAt DateTime @default(now())
}
```

#### 举报入口位置
| 位置 | 组件 | 说明 |
|------|------|------|
| 讨论列表 | ActionMenu | 三点菜单 |
| 讨论详情 | DiscussionReportButton | 标题右侧按钮 |
| 讨论评论 | ActionMenu | 操作菜单 |
| Issue 详情 | 举报按钮 | 标题右侧 |
| Issue 评论 | ActionMenu | 操作菜单 |
| PR 详情 | 举报按钮 | 标题右侧 |
| PR 评论 | ActionMenu | 操作菜单 |
| 仓库页面 | ActionMenu | 操作菜单 |

#### API 接口
```typescript
// 提交举报
POST /api/v1/reports
{ targetType, targetId, reason, description? }

// 获取举报记录
GET /api/v1/me/reports?page&pageSize&status

// 屏蔽用户
POST /api/v1/me/blocks
{ userId, reason? }

// 获取屏蔽列表
GET /api/v1/me/blocks?page&pageSize

// 取消屏蔽
DELETE /api/v1/me/blocks?userId=xxx
```

## 安全与分享

### 分享链接系统

```prisma
model ShareLink {
  id          String    @id @default(cuid())
  token       String    @unique
  repoId      String
  path        String?   // 指定路径
  permission  String    @default("read")  // read/download/write
  password    String?   // 可选密码保护
  expiresAt   DateTime? // 过期时间
  maxViews    Int?      // 最大浏览次数
  viewCount   Int       @default(0)
  isActive    Boolean   @default(true)
  createdAt   DateTime  @default(now())
}
```

### 安全防护层

| 防护层 | 实现 |
|--------|------|
| XSS 防护 | DOMPurify HTML 净化 |
| CSRF 防护 | Origin 验证 + Token |
| SQL 注入 | Prisma 参数化查询 |
| 文件上传 | Magic Bytes 检测 + 内容扫描 |
| 敏感操作 | 二次验证确认 |
| 速率限制 | Redis 令牌桶算法 |

```
    ↓                          ↓

```

## 数据库模型汇总

### 用户相关
```prisma
model User {
  id            String   @id @default(cuid())
  username      String   @unique
  email         String   @unique
  password      String
  role          String   @default("user")
  bio           String?
  avatarUrl     String?
  isMuted       Boolean  @default(false)
  mutedUntil    DateTime?
  createdAt     DateTime @default(now())
}
```

### 仓库相关
```prisma
model Repository {
  id          String   @id @default(cuid())
  name        String
  ownerId     String
  description String?
  isPrivate   Boolean  @default(false)
  totalSize   BigInt   @default(0)
  maxSize     BigInt   @default(10737418240)  // 10GB
  stars       Int      @default(0)
  forks       Int      @default(0)
  createdAt   DateTime @default(now())
}

model RepoItem {
  id          String   @id @default(cuid())
  repoId      String
  name        String
  type        String   // "file" | "folder"
  path        String
  parentPath  String
  content     String?
  size        BigInt   @default(0)
  mimeType    String?
  extension   String?
  isDeleted   Boolean  @default(false)
  createdAt   DateTime @default(now())
}
```
