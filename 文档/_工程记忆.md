## 回滚指南

### 如何回滚举报功能

1. **删除 API 文件**
   ```bash
   rm src/app/api/v1/me/reports/route.ts
   rm src/app/api/v1/me/blocks/route.ts
   ```

2. **恢复 settings 页面**
   ```bash
   # 使用 git 恢复
   git checkout HEAD~1 -- src/app/\(main\)/settings/page.tsx
   ```

3. **验证**
   ```bash
   npm run lint
   npm run build
   ```

### 如何回滚 Repo 组件拆分

1. **恢复 page.tsx**
   ```bash
   git checkout HEAD~2 -- "src/app/(main)/[username]/[repoName]/page.tsx"
   ```

2. **删除拆分组件**（可选）
   ```bash
   rm src/components/repo/RepoTypes.ts
   rm src/components/repo/RepoIssuesTab.tsx
   rm src/components/repo/RepoPullsTab.tsx
   rm src/components/repo/RepoSettingsTab.tsx
   rm src/components/repo/RepoDownloadModal.tsx
   rm src/components/repo/RepoShareModal.tsx
   rm src/components/repo/RepoForkRequestModal.tsx
   ```
